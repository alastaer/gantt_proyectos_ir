⚙️ Configuración de GitHub (necesaria solo para guardar cambios)

El token se guarda solo en este navegador (localStorage), nunca se sube al repositorio. Genera uno en GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens, dando acceso únicamente a este repositorio y permiso "Contents: Read and write". Sin esto configurado, puedes seguir viendo y editando en pantalla, pero el botón "Guardar cambios en GitHub" no podrá confirmar el commit.
